NCES 2026 DIGITAL POSTER WEBSITE

Files:
- index.html : website landing page
- poster.pdf : uploaded poster PDF

FREE PUBLISHING OPTION: GitHub Pages
1. Sign in or create an account at https://github.com/
2. Create a NEW PUBLIC repository, for example: nces-2026-poster
3. Upload BOTH index.html and poster.pdf into the repository root (top level).
4. Open repository Settings -> Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish. The URL will look like:
   https://YOUR-USERNAME.github.io/nces-2026-poster/
   Use the exact URL shown in Settings -> Pages.
8. Open the published URL on your phone and test the PDF link.
9. Generate the QR code only after the website URL works. A QR generator can encode that exact URL; print/test the QR before placing it on the poster.

IMPORTANT:
- Keep the repository public if you want anyone at the conference to open the page without signing in.
- Do not share passwords or account credentials.
- The QR code is not included yet because the final public website URL does not exist until you publish it.
- If you later add an MP4, upload it and add a video section; large videos may be better hosted on a public video platform and embedded.
